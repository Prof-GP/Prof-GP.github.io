Privacy Policy

Explainer Poster · Last updated November 22, 2026

Explainer Poster ("the tool") is a private publishing tool. Its only user is its owner, who uses it to upload the owner's own educational videos to the owner's own YouTube channel ("Practical Forensics") and Instagram account (@practical4n6).

Use of YouTube API Services

The tool uses YouTube API Services to upload videos and manage them on the owner's YouTube channel. By using the tool, you agree to be bound by the YouTube Terms of Service. YouTube's handling of data is described in the Google Privacy Policy, available at https://policies.google.com/privacy.

What information is accessed

With the permission granted when signing in with Google, the tool accesses only the owner's own YouTube channel:

  • basic channel information (channel name and ID), to confirm the right channel is connected;
  • the owner's own videos and playlists, to upload videos and set their title, description, tags, captions, thumbnail and playlist;
  • basic statistics for the owner's own videos (such as views), to see which lessons are useful.

The tool does not access, collect or store information about viewers or any other person. It does not use cookies or tracking, and this website does not either.

How information is used and shared

The information is used only to publish and manage the owner's own videos. It is not sold, shared with third parties, or used for advertising. The tool does not download, cache or re-host YouTube content.

Storage

The only stored data are the access credentials (an OAuth refresh token), kept as an encrypted secret in the owner's private code repository and on the owner's own computer, and a list of the video IDs the tool uploaded. Nothing else is stored.

Revoking access and deleting data

Access can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions. When access is revoked, or on request, the stored credentials are deleted within 7 days. Any data obtained through the YouTube API Services is deleted or refreshed within 30 days, as required by the YouTube API Services Developer Policies.

Contact

Questions about this policy: send a message to @practical4n6 on Instagram.
